# 2026 커밋 은하

2026년 깃허브 커밋을 날짜와 분야로 나누어 3D 나선 은하로 그린 페이지입니다.

- 바로가기: https://greatsong.github.io/commit-galaxy/
- 다른 계정 보기: 페이지의 조회 상자에 깃허브 아이디를 넣거나 주소 뒤에 `#아이디`를 붙입니다. 예: https://greatsong.github.io/commit-galaxy/#octocat
- 다른 계정은 공개 저장소 기본 브랜치의 커밋만 GitHub 검색 API로 받습니다. 로그인 없이 1분에 10번까지 조회할 수 있어서 커밋이 많으면 1분씩 기다리며 이어서 받습니다.
- greatsong 자료는 2026년 10월 27일에 수집해 페이지에 넣었습니다. 비공개 저장소는 이름·설명·커밋 메시지를 지우고 시각만 남겼습니다.

파일 하나(`index.html`)로 동작하며 서버와 API 키가 없습니다. 3D 화면은 three.js r128로 그립니다.
